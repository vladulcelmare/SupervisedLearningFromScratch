# SupervisedLearningFromScratch

Repository containing my Kaggle notebooks on which I learned Supervised ML from scratch, on my own.

## Content

Python based notebooks developed on Kaggle that implement most Supervised ML algorithms

## Requirements

* uv (or any other venv)
* pandas
* numpy
* xgboost
* scikit-learn
